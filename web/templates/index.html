🐱 猫抓 (Cat-Catch) 集成配置

参考官方文档：cat-catch.94cat.com/docs/settings#send

方式一：POST JSON（推荐）

猫抓 → 设置 → 调用程序 → 新增，配置如下：

① 请求方式：POST

② 地址：

http://localhost:8080/api/download

③ Content-Type：application/json

④ 请求体（标签会被猫抓自动替换）：

{"url":"${url}","title":"${title}","referer":"${referer}","cookie":"${cookie}","userAgent":"${userAgent}","fullFileName":"${fullFileName}"}

方式二：GET（简单模式）

调用程序地址模板：

http://localhost:8080/api/download?url=${url}&title=${title}&referer=${referer}

常用替换标签

标签说明示例
${url}资源地址https://bmmmd.com/test.mp4
${referer}资源请求头；不存在则不输出https://bmmmd.com/
${initiator}类似永远有值的 refererhttps://bmmmd.com
${webUrl}资源播放页面地址https://bmmmd.com/test.html
${title}播放页面标题测试视频
${fullFileName}完整文件名（作为保存名）test.mp4
${fileName}文件名不含扩展test
${userAgent}User AgentMozilla/5.0 ...
${cookie}资源 Cookie（需猫抓 2.3.8+）key=value;key2=value2;

注：POST body 中 cookie、userAgent 等字段为空时服务端会自动忽略。

curl 测试

curl "http://localhost:8080/api/download?url=...&title=test&referer=..."
curl -X POST "http://localhost:8080/api/download" \ -H "Content-Type: application/json" \ -d '{"url":"https://example.com/video.m3u8","title":"我的视频","referer":"https://example.com/"}'

API 端点参考

方法路径说明
GET/POST/api/download触发下载（querystring 或 JSON body）
GET/api/tasks获取所有任务状态
DELETE/api/tasks/{id}取消任务；加 ?action=delete 删除已完成任务
POST/api/tasks/{id}/retry重试失败任务
GET/api/tasks/{id}/log获取任务完整日志
GET/api/config获取全局配置
PUT/api/config更新全局配置
GET/api/files列出下载目录文件
GET/wsWebSocket 实时推送
