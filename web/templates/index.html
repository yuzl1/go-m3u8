🐱 猫抓 (Cat-Catch) 集成配置

在猫抓扩展的 "调用程序" 设置中，添加以下配置：

方法一：自定义调用（推荐）

猫抓 → 设置 → 调用程序 → 添加，填入：

http://localhost:8080/api/download?url=${url}&title=${title}&referer=${referer}

变量说明：${url} = m3u8地址, ${title} = 页面标题, ${referer} = 来源页

方法二：curl POST（脚本调用）

curl -X POST "http://localhost:8080/api/download" \ -H "Content-Type: application/json" \ -d '{"url":"https://example.com/video.m3u8","title":"我的视频","referer":"https://example.com/"}'

API 端点参考

方法路径说明
GET/POST/api/download触发下载（querystring 或 JSON body）
GET/api/tasks获取所有任务状态
DELETE/api/tasks/{id}取消任务；加 ?action=delete 删除已完成任务
GET/api/config获取全局配置
PUT/api/config更新全局配置
GET/wsWebSocket 实时推送
